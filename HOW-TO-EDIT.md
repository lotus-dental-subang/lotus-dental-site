# How to add a dental guide to the Lotus Dental website

## 1. Open the edit screen
Go to **lotusdentalsubang.com/admin** (for now: **lotus-dental-site.pages.dev/admin**) and click **Login with GitHub**.
The first time, GitHub asks you to approve "Lotus Dental edit screen". Click **Authorize**.

## 2. Write a new guide
1. Click **+ Dental guide**.
2. Fill in the boxes:
   - **Title**: short and clear, e.g. *How long do braces take?* (this also becomes the page address)
   - **Google summary**: 1–2 sentences. Google shows this under the title.
   - **Date**: today's date is already filled in.
   - **Main photo**: a wide photo. Please use the clinic's own photos.
   - **Treatment**: e.g. *braces*. The box at the end will say "Questions about braces?" with the WhatsApp button.
   - **Note at the top** (optional): e.g. *Prices may change. WhatsApp us for today's price.*
   - **Article**: write the guide. Use **H2** for section headings. To add a WhatsApp link, make a link and type `whatsapp` as the address.
3. The right side shows how the page will look.

## 3. Save it as a draft
Click **Save**. The guide now waits in **Workflow** as a draft.
Set it to **In review** when it is ready.

## 4. Approval
Asyiqin checks it, sets it to **Ready**, then clicks **Publish → Publish now** and **OK** on "Are you sure?".
The page goes live in about 1 minute.

## Please remember
- Write in your own words. Do not copy text from other websites.
- No "best dentist" or "painless" claims, and check every price with the dentist first (Malaysian dental advertising rules).
- Before/after photos only with the patient's written permission.

Questions? WhatsApp Asyiqin.
